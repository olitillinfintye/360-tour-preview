Dembi Resort: 360 VR Tour preview

This is a browser mock-up of the experience I will build in the Tour scene using the existing Complete 360 Tour (C360) system. Nothing has been changed in Unity yet. The tour starts at Main Gate 1, where the menu is.
Preview featureHow it will be built in Unity (Tour scene)
35 panorama locationsNew tour asset Assets/Tours/Dembi Tour.asset: one C360 ImageNode per image in Video/360Images, named after the image (e.g. "Main Gate 1"). Entry node: Main Gate 1. Texture import is fixed (no mipmaps, higher max size) for sharp, seamless panoramas. The Example Tour is left untouched.
Menu at Main Gate 1World-space uGUI canvas placed in the Main Gate 1 panorama (C360 PrefabElement). It has one button per main area, named after the images (Main Gate, Reception, Restaurant, Lakeshore, Lookout Pier, Lake, Bridge, Waterfall, Compound, Massage Room, Room, Room 2nd, Room 3rd). Each button jumps to the first image of that area.
Ray interaction on canvasesC360VrPointer extended so the controller laser drives any world-space canvas (Buttons, Toggles, Sliders, Scroll views) through the EventSystem, plus the C360 hotspots and popups. Hover highlight, trigger = click, and the laser stops at the hit point with a cursor.
Navigation hotspots (teal)C360 HotspotElement using the existing Hotspot prefab, labelled with the destination name.
Info points (blue)PrefabElement with Text Popup prefab variants (title + body). The text here is placeholder you can change.
Resort Map (amber)PrefabElement with an Image Popup variant showing the map image.
Entry view per locationNode entryYaw + the existing EntryYawReactor.
Guided TourC360 AutoTour component (same route, 12 s per stop).
Scene fadeC360 FadeTransition. The original fade effect does not render under URP, so I will add a URP-compatible fade.
Top-left label, toolbar, edit panelPreview-only helpers; they are not part of the VR build.
Tip: use ✎ Edit to move any hotspot (or the menu) that isn't exactly where you want it, then press Save to project. I'll use your saved layout when building the Unity version.
